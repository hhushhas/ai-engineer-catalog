## Practical Takeaways

- XOR is often used as a classic beginner example for neural networks because it looks simple, but it cannot be solved by a single straight line.
- XOR returns true when two inputs are different and false when they are the same.
- It is just a small function that takes two Boolean values and returns whether they are different.
- Instead, we take input values, multiply them by weights, add biases, pass the result through an activation function, and get an output.
- In other words, instead of hardcoding the rule, we let the network learn the right weights from data.
