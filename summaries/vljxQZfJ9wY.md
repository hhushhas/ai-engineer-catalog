## Practical Takeaways

- But agentic systems have fundamentally changed what the evaluation means.
- Today I would like to discuss how evaluation is evolving from model benchmarking into production infrastructure.
- A benchmark doesn't capture tool failure, API outage, context changes, user variability, long running workflows.
- At the highest layer, you have to think about multi-agent coordination failures.
- And this is why evaluating only model output misses the most production risk we observe.
