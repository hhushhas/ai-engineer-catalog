## Gist

You typed a request into a small box to a super intelligence and then you waited.

## Why Hasan Should Care

This session maps to context engineering. For Hasan's work, the useful lens is whether it changes how to build, evaluate, ship, or operate AI-enabled products and agent workflows (20:13).

## Practical Takeaways

- There's an ocean of meaning in an ordinary human request, context, nuance, intent, all things we've never had to spell out to each other.
- We learn tricks, send tips to use code skills, or rewrite prompts a certain way to manage this.
- Reasoning, speech, vision, memory, planning, all curving upwards.
- The human still decides what context matters, still remembers what to ask, still chooses the timing, still notices the ambiguity, still repairs the output, still has to carefully engineer a prompt.
- OpenAI released GPT real-time 2 in late May and started trying it for their voice mode as well.

## Implementation Ideas

- Look for reusable context packets, skill files, memory rules, and workflow prompts.
