## Gist

In 2026, coding agents will quietly retire their first software platform.

## Why Hasan Should Care

This session maps to context engineering. For Hasan's work, the useful lens is whether it changes how to build, evaluate, ship, or operate AI-enabled products and agent workflows (17:33).

## Practical Takeaways

- For customers and partners, this means durable execution right on top of their existing infrastructure with minimal additional dependencies.
- When we talk about agentic engineering we focus all of our attention on verification.
- But today I want to focus on the specification instead and more importantly how can agents participate in specifying the system not just building or verifying it.
- Once those decisions were written down, the agent was indeed able to implement the production system.
- And once these algorithms are discovered, tested and verified in simulation, then we ask the agent to write the concrete specification.

## Implementation Ideas

- Look for reusable context packets, skill files, memory rules, and workflow prompts.
